# When it comes back wrong

Find the symptom, then work the right-hand column in the order it is written and
stop when it is fixed. Almost none of these are sampler problems, and reaching
for `-s` first is the most reliable way to spend fifteen minutes and learn
nothing.

| Symptom | What to change, in order |
| --- | --- |
| **Lines skipped, a verse missing, the bridge raced through** | Redo the duration arithmetic (SKILL.md §4) -- a crammed container is far and away the commonest cause, and a run still on the 120 s default never chose a length at all. Then shorten lines, even out syllables within a section, simplify the form, strip stacked tag modifiers, and draw four fresh seeds. Not more steps: skipping is reported at every step count there is, so no number of them guarantees delivery. |
| **An instrument nobody asked for** | Read the plan's reasoning caption (`planning.md`) -- it usually named it first. Then cut the contradiction in `-p` that invited it and state a short positive palette. There is nowhere to put a negative, so "no guitars" is just the word *guitars* in your caption. Re-plan, or drop `--plan` and see if it was the LM's idea. |
| **The chorus is no bigger than the verse** | Put the arc in `-p` and not only in the tags (SKILL.md §1, rule 7): the model will happily render one texture for four minutes. Check the prompt for judgement words that name an endpoint with nothing to be big *relative to* -- "huge chorus" with no sparse verse described is the classic. Shorten the hook so it has room to open up, make the verse genuinely sparse in the writing, and expect to finish the contrast with a fader. |
| **Harsh, brittle, hissy, everything at one level** | Expected on a turbo draft, and mostly a checkpoint artefact rather than a prompt problem. Measured on one plan rendered both ways: the turbo draft pinned its peak at 0.999 with 0.27 stereo width, and sft came back at 0.877 with 0.83. **Width and headroom are what separate them; dynamic range barely moves** (5.9 dB against 7.5), so do not expect sft to supply a contrast the prompt never asked for. Render on sft before chasing it, then audition more seeds, then fix it in the mix. `${CLAUDE_SKILL_DIR}/scripts/check-take.py` tells you which of the two you are looking at. |
| **The planner changed the voice, the genre or the language** | `planning.md`, and it is the reason that file exists. Read the block, say the thing twice in different words, re-plan at a new seed. If it keeps drifting, drop `--plan`: the direct path cannot contradict you, having no opinion to contradict you with. |
| **Vocals in something meant to be instrumental** | Empty lyrics is the reliable form; a tag-only sheet is not. Strip every vocal word from `-p` as well -- "female vocals", "topline", "choir", "sung" -- and do not write "no vocals", which adds the word. Then draw more seeds. |
| **Wrong language, or an accent you did not ask for** | `--language` has to match the words, and matching it is necessary rather than sufficient: upstream names multilingual lyric compliance as a standing limitation and English as the safe case. Non-English takes need more seeds and more listening; `zh_rap` is called out on the model card as its own weak spot. |
| **The run refuses to start** | Read the message and believe it. Prompt over 256 tokens, lyrics over 2048, `--time-signature` outside `(2, 3, 4, 6)`, `--bpm` outside 30--300, output not `.flac`, `--plan` together with `--audio-codes`, or a plan with fewer codes than the duration needs. All of it is checked before a single weight loads, which is why a typo costs a second. |
| **Every take of a batch sounds the same kind of wrong** | That is the prompt or the sheet, not the draw -- seeds vary the performance, not the brief. Change one thing in `-p` and redraw the same four seeds so the comparison still means something. |
| **It is fine but forgettable** | Nothing here fixes that, and more seeds will not. Go back to SKILL.md §0: a song with no answer to "what should the listener feel by the last chorus" tends to render as competent wallpaper. Rewrite the hook, then draft again. |
